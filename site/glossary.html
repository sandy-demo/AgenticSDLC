Glosarium dan pertanyaan umum

Istilah

Agentic SDLC
Pemakaian agent di beberapa tahap kerja perangkat lunak, dengan manusia di titik keputusan.
Copilot cloud agent
Agent yang mengerjakan tugas di latar belakang dan mengusulkan perubahan lewat PR.
Custom agent
Profil peran dengan instruksi dan daftar tool, misalnya QA Engineer.
Skill
Prosedur berulang yang dimuat saat relevan, misalnya aturan menambah endpoint.
MCP
Protokol untuk menghubungkan agent ke tool dan data dengan izin yang sesuai.
Hook
Program kecil yang bereaksi pada fase sesi, misalnya sebelum tool dijalankan.
gh-aw
Compiler yang mengubah workflow berorientasi agent dari Markdown menjadi GitHub Actions.
Safe outputs
Daftar bentuk perubahan yang boleh diminta agent; job terpisah memvalidasi dan menerapkannya.
Premium request / AI credit
Istilah penggunaan pada versi paket yang berbeda. Workshop memakai AI credits sesuai dokumentasi saat dicek; keduanya bukan satuan yang otomatis setara.
Branch protection
Aturan merge dan push yang diterapkan repository, terpisah dari instruksi agent.
ADR
Catatan tentang keputusan arsitektur, alternatif, dan konsekuensinya.
Draft PR
Usulan perubahan yang belum dinyatakan siap untuk merge.

FAQ

Bolehkah agent merge sendiri?

Tidak di workshop ini. Branch protection dan manusia yang meninjau menentukan keputusan; S04 tidak di-merge.

Apa bedanya memberi chat dan mendelegasikan issue?

Chat membantu memahami. Issue memberi kriteria dan identitas tugas, lalu menerima tautan hasil dan jejak review.

Haruskah punya Copilot untuk mengikuti workshop?

Tidak untuk materi offline, aplikasi lokal, dan fixture. Periksa paket dan policy sebelum mencoba fitur cloud.

Kenapa CodeQL tidak menghasilkan alert yang ditunjukkan?

S10 memakai ilustrasi yang aman. Jangan menganggap kartu simulasi sebagai alert sungguhan; laporkan hasil scan aktual apa adanya.

Apakah hook menggantikan sandbox atau izin?

Tidak. Hook adalah lapisan tambahan, bukan jaminan keamanan. Hak akses, sandbox, dan branch protection tetap berlaku.

Ke mana biaya masuk?

Model dan token memengaruhi AI credits; Actions dan langganan terpisah. Pemilik memantau dashboard dan anggaran.

Bisakah PM mulai dari Jira atau Teams?

Bisa jika paket mendukung integrasinya dan kebijakan organisasi mengizinkan. Versi personal memakai GitHub Issue.

Bagaimana mengulang tanpa menghapus pekerjaan?

Restart aplikasi lokal untuk seed awal. Buat checkout latihan baru dengan npm run reset -- --fresh; remote tidak diubah.

Apakah buka situs ini menjalankan Express atau Copilot?

Tidak. Situs, diagram, grafik dan simulasi halaman semuanya offline. Aplikasi dan GitHub dimulai secara terpisah.
