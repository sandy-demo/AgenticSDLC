S14 · Governance

Batasi aksi agent. Ukur biaya terpisah.

Ibu Maya butuh jawaban konkret: siapa bisa menulis ke repo, apa yang diblok, dan di mana biaya terlihat?

Empat kontrol yang berbeda

Branch protection

Review dan checks wajib di main. Repository owner mengatur; Tech Lead meninjau.

Hook + audit

Hook memeriksa panggilan tool. Audit workshop hanya metadata dan tidak menjadi batas keamanan tersendiri.

Permissions + safe outputs

Agent membaca dengan izin minimum. Job terpisah hanya boleh memproses output yang dipilih, misalnya satu draft PR docs.

Anggaran

Periksa kuota dan pemicu workflow; aktifkan hanya saat latihan. Audit organisasi terpisah dari audit lokal.

Uji fixture tanpa menjalankan argumen:

npm run guard:demo

Berapa biayanya?

Ilustrasi: jika pemakaian di luar kuota mencapai 25 AI credits, 25 × US$0,01 = US$0,25. Bukan estimasi satu sesi dan bukan tagihan.

Tarif konversi diambil dari GitHub Docs — Usage-based billing for individuals, diperiksa 25 November 2026. Satuan USD per AI credit untuk akun personal; contoh tidak memasukkan langganan, pajak, atau biaya Actions. Token yang digunakan dan model menentukan jumlah kredit. Periksa dashboard paketmu untuk pemakaian aktual.
