15 skenario Agentic SDLC

Pilih level dan persona, atau cari masalah yang ingin kamu coba. S06 dan S14 punya versi lokal/personal serta versi organisasi.

15 skenario tersedia.

S01 · Level 1

Beri agent aturan kerja tim

Copilot CLI: dua prompt identik selesai; bukti UI Agent Mode VS Code belum ada

Rani bolak-balik revisi karena Bima memakai konvensi yang belum tertulis.

Rani, Bima

S02 · Level 1

Ubah fitur di beberapa file

Draft #29 punya perubahan lintas file; browser dan 4 tes UI lulus lokal

Pilihan kategori terlihat kecil, tetapi menyentuh form, payload, penyimpanan, dan tes.

Bima

S03 · Level 1

Pakai skill untuk endpoint baru

Endpoint komentar berfungsi pada draft #25; laporan skill cloud dan tes lokal tercatat

Developer membangun route dengan cara berbeda; Yoga sulit membandingkan log.

Rani, Yoga

S04 · Level 2

Delegasikan issue, tinjau draft PR

Retry Copilot #20 berfungsi lokal; #4 tetap kosong, CI draft baru masih perlu izin

Backlog validasi tak tersentuh. Tanggal besok pada klaim taksi Rp250.000 bisa tersimpan.

Hendra, Bima

S05 · Level 2

Pulihkan CI merah karena timezone

Draft #27 punya fix; fixture dan 14 tes validasi per zona lulus lokal

Log panjang menyembunyikan beda kalender antara zona waktu Jakarta dan LA.

Rani, Bima, Yoga

S06 · Level 2 · Opsi organisasi

Delegasikan perubahan dari tiket

Versi GitHub Issue personal selesai diuji · versi Jira/Teams tetap manual/org

Lina ingin mengganti label Submit, tetapi tiket kecil ikut antre sprint.

Lina, Rani

S07 · Level 2

Modernisasi adapter tanpa big bang

S07a #18 dan S07b #23 menghasilkan diff; kontrak lulus pada kedua snapshot

Adapter ekspor CSV berbasis callback tidak punya tes karakterisasi.

Hendra, Bima

S08 · Level 3

QA menemukan bug tepat di batas

Draft QA #24 test-only; bug batas sekarang terbukti pada helper dan API

Sari perlu tahu apakah Rp1.000.000 sudah meminta keputusan Finance.

Sari, Hendra

S09 · Level 3

Tinjau PR dengan tiga spesialis

Review Copilot pada #2 dan #20 tercatat · tiga sesi spesialis #2, bukan approval manusia

Sari tidak bisa sendirian menguji performa, privasi, dan audit tiap PR.

Sari, Dimas, Bima

S10 · Level 3

Latih alur CodeQL Autofix

CodeQL aktif · 0 alert terbuka pada pemindaian awal; autofix belum diuji

Daftar alert yang panjang tidak memberi Bima informasi cukup untuk meninjau perbaikan.

Dimas, Bima

S11 · Level 3

Setujui desain sebelum implementasi

Architect menghasilkan draft ADR #22; tidak ada approval atau implementasi

Logika retry approval dibahas terlambat dan bisa memicu kerja ulang.

Rani, Bima

S12 · Level 4

Sinkronkan API docs lewat draft PR

Target diperbaiki dan dicoba di draft #33; provider tetap 403; pembanding docs #28 teruji

Docs masih menyebut items, padahal API mengirim claims.

Bima, Yoga

S13 · Level 4

Triage issue dan diagnosis CI

Pemicu live teruji · Copilot CLI HTTP 403; label dan komentar belum terbit

Issue tanpa detail menunda triage; error serupa dianalisis berulang.

Yoga, Bima

S14 · Level 5 · Opsi organisasi

Batasi aksi agent dan ukur biaya

Fixture guardrail dan audit teruji; kredit sesi GitHub direkam terpisah

Ibu Maya tidak mau membuka akses agent tanpa kontrol dan penanggung jawab biaya.

Ibu Maya, Hendra, Yoga

S15 · Level 5

Capstone: klaim multi-mata-uang

Template tersedia, epik dan ADR nyata; belum masuk implementasi/merge

Lina perlu klaim IDR, USD, dan SGD. Tanpa desain dan gate, review serta docs menyusul belakangan.

Lina, Rani, Bima, Sari, Dimas, Yoga, Hendra, Ibu Maya
