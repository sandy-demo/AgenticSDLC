S15 · Capstone

Satu fitur, delapan tahap penyerahan

Lina ingin klaim IDR, USD, dan SGD. Setiap tahap menghasilkan artefak yang diteruskan ke orang atau agent berikutnya. Hanya Tech Lead yang boleh merge di repo turunan.

Ini rencana dan timeline latihan. Baseline hanya menerima IDR; belum ada live run atau fitur multi-currency yang sudah selesai.

Langkah latihan capstone.

Ikuti perjalanan epik

1 · Pecah epik

Lina + Planner. Susun draf issue ADR, API/UI, tes, dan docs; manusia menyetujui penugasan.

Perbesar S15-02-breakdown.png

2 · Setujui ADR

Architect + Bima. Sepakati sumber kurs, waktu kurs dan pembulatan sebelum menulis kode.

Belum direkamS15-03-adr.png

3 · Buka draft PR

Copilot. Ajukan perubahan di branch dan tautkan epik serta tes.

Belum direkamS15-04-pr.png

4 · Periksa checks

GitHub Actions. Jalankan tes. Jika merah, periksa penyebab sebelum lanjut.

Belum direkamS15-05-ci.png

5 · Review dan scan

Reviewer + CodeQL. Pisahkan saran model, temuan terverifikasi, dan keputusan manusia.

Belum direkamS15-06-reviews.png

6 · Putuskan merge

Bima. Merge hanya pada repo latihan setelah review persetujuan dan checks terpenuhi.

Belum direkamS15-07-merge.png

7 · Sinkronkan docs

Docs Sync + Triage. Ajukan draft PR dokumentasi dan rapikan issue tindak lanjut bila diaktifkan.

Belum direkamS15-08-docs.png

8 · Tinjau audit

Yoga + Ibu Maya. Periksa keputusan hook dan penggunaan AI credits secara terpisah.

Perbesar S15-09-audit.png

Waktu per tahap

Versi ringkas: tunjukkan epik, draft PR, review, lalu keputusan merge. Untuk materi tanpa akses cloud, mulai dari bukti lokal S04.
